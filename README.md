# MedMask

Настольная программа для локального обезличивания папки с медицинскими
документами. Сервер, браузер, авторизация, облачное хранилище и сетевые запросы
отсутствуют.

## Как работает готовая программа

1. Пользователь запускает MedMask.exe в Windows или MedMask.app в macOS.
2. Выбирает папку с историями и нажимает «Обезличить».
3. Рядом создаётся папка «Обезличенные».
4. Исходные файлы остаются без изменений, а результаты получают безопасные
   имена document_0001.pdf, document_0002.pdf и так далее.
5. В новой папке создаётся _ОТЧЁТ.txt без исходных имён и фрагментов
   медицинского текста.

Пользователю не нужно устанавливать Python или библиотеки: они включаются
в автономную сборку.

## Форматы

Поддерживаются PDF, DOCX, RTF, ODT, ODG, TXT, XLSX и XLSM. Все результаты
пересобираются как новые текстовые PDF без исходных метаданных, аннотаций,
форм и изображений.

Маскируются ФИО пациентов и медработников, даты рождения, адреса, телефоны,
email, СНИЛС, ИНН, паспортные данные, полисы, места работы и номера медицинских
карт. Дата рождения заменяется рассчитанным возрастом.

OCR пока отсутствует. JPG/PNG и PDF-страницы без извлекаемого текста не
распознаются; программа помечает их в отчёте для ручной проверки.

Автоматические правила не дают абсолютной гарантии. Перед передачей документов
итоговые PDF необходимо просмотреть.

## Общий код и сборки

Движок и интерфейс общие для обеих систем:

- Windows x64: scripts/build_windows.ps1 создаёт dist\MedMask.exe;
- macOS Apple Silicon: scripts/build_macos.command создаёт dist/MedMask.app.

Сборка требует Python только у разработчика. Также добавлен закрытый
GitHub Actions workflow .github/workflows/build-desktop.yml, который может
собрать оба артефакта на соответствующих операционных системах.

## Локальная разработка

~~~bash
python3 -m venv .venv
.venv/bin/python -m pip install ".[build]"
.venv/bin/python -m pytest
.venv/bin/python main.py
~~~
