# MedMask

MedMask — небольшое веб-приложение для обезличивания текстовых медицинских PDF
прямо в браузере. Исходный документ не отправляется на сервер, не сохраняется в
базе и не попадает в журнал загрузок. Приложение можно открыть по облачной ссылке
или запустить локально.

## Локальный запуск

Требуется Node.js 22 или новее.

- macOS: двойной клик по `start-local.command`;
- Windows: двойной клик по `start-local.bat`;
- вручную: `pnpm install`, `pnpm build`, затем
  `pnpm start --hostname 127.0.0.1 --port 8765`.

После запуска откроется `http://127.0.0.1:8765`.

## Что происходит с документом

1. PDF читается библиотекой PDF.js внутри вкладки браузера.
2. Текст очищается от ФИО, адресов, телефонов, email, СНИЛС, ИНН, паспортов,
   полисов, номеров медкарты, места работы и даты рождения.
3. Создаётся новый текстовый PDF без исходных картинок, форм, подписей,
   аннотаций и метаданных.
4. Результат доступен по временному адресу в памяти вкладки и исчезает после
   очистки или закрытия страницы.

Никаких API-запросов с содержимым файла приложение не выполняет. D1/R2 и другие
хранилища не подключены.

## Ограничения

- Поддерживается PDF размером до 120 МБ.
- OCR отсутствует. Страницы-сканы заменяются предупреждением и требуют ручной
  проверки.
- Исходное оформление и таблицы не сохраняются: результат пересобирается как
  чистый текст.
- Автоматические правила не дают абсолютной гарантии. Перед передачей внешней
  системе итоговый PDF необходимо просмотреть.
